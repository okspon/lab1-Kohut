Лабораторна робота No1
• Тема: Створення першого проєкту. Класи, об’єкти, конструктори та деструктори.
Середовище розробки.
• Тривалість: 2 год
• Інструмент: .NET SDK, Visual Studio Code, Git
Мета
Ознайомитися з середовищем розробки, навчитися створювати класи та працювати з базовими
елементами ООП у C#. Налаштувати середовище розробки.
Теоретичні відомості
• Клас - це шаблон для створення об’єктів. Він описує, які дані (поля) та яку поведінку
(методи) матимуть його екземпляри.
• Конструктор - це спеціальний метод, що автоматично викликається під час створення
нового об’єкта (new ClassName()). Його основне завдання - ініціалізувати початковий стан
об’єкта.
• Деструктор - це метод, що викликається перед тим, як об’єкт буде знищено збирачем
сміття. У C# використовується рідко, але демонструється для розуміння життєвого циклу
об’єкта.
• Інкапсуляція - це механізм приховування внутрішніх деталей реалізації. Доступ до даних
класу контролюється через публічні властивості (get, set), тоді як самі дані зберігаються у
приватних полях.
