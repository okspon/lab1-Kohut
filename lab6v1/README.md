# Лабораторна робота No4
• Тема: Наслідування. Ключові слова base, override, virtual. Приховування членів (new).

## Мета
Навчитися створювати ієрархії класів, використовувати ключові слова base, virtual, override
для реалізації поліморфізму, а також розуміти відмінності між override та приховуванням членів
за допомогою new.

## Хід роботи

У цій лабораторній роботі я створила консольний C#-проєкт lab6v1 та реалізувала ієрархію класів Instrument -> Guitar / Piano, застосувавши наслідування, 
ключове слово base для передачі параметрів у конструктор базового класу, а також модифікатори virtual та override для забезпечення поліморфної поведінки при виклику методів. Крім того, 
я реалізувала приховування невіртуального методу базового класу за допомогою модифікатора new у класі Guitar 
та на практиці продемонструвала різницю між статичним зв'язуванням (при new) і динамічним зв'язуванням (при override) під час звернення до об'єктів через посилання різних типів.

## Контрольні запитання

1. Поясніть принцип наслідування в ООП. Наведіть приклад з реального світу.
   
Наслідування — це механізм ООП, який дозволяє створити новий клас (похідний/нащадок) на основі вже існуючого (базового/батьківського). Клас-нащадок автоматично успадковує всі публічні та захищені поля, властивості та методи базового класу, що дозволяє повторно використовувати код та будувати логічні ієрархії типів за принципом «є-різновидом».
Приклад з реального світу: Базовий клас «Транспортний засіб» (має властивості: марка, швидкість та метод: рухатися). Похідні класи «Легковий автомобіль» та «Вантажівка» успадковують ці параметри, але додають власні унікальні риси: легковик має тип кузова, а вантажівка — вантажопідйомність.

2. Для чого використовується ключове слово base? Наведіть приклади його застосування.
   
Ключове слово base використовується у похідному класі для доступу до членів базового класу.
Основні випадки застосування:

Викликати конструктор базового класу (щоб ініціалізувати успадковані приватні чи публічні поля):

```
     public Guitar(string brand, decimal price, int numStrings) : base(brand, price)
     {
         NumStrings = numStrings;
     }
     ```
   * **Звернутися до успадкованого методу базового класу**:
     ```csharp
     public override void PlaySound()
     {
         base.PlaySound();
         Console.WriteLine("Додатковий звук гітари");
     }
```
3. У чому полягає різниця між virtual та override? Як вони забезпечують поліморфізм?

virtual використовується у базовому класі для позначення того, що метод, властивість чи індексатор можуть бути перевизначені у похідних класах.
override використовується у похідному класі для надання нової реалізації віртуального члена базового класу.
Як вони забезпечують поліморфізм: Вона вмикають динамічне (пізнє) зв'язування. Коли ви викликаєте метод через змінну базового типу (наприклад, Instrument inst = new Guitar()), програма під час виконання дивиться не на тип змінної, а на реальний тип об'єкта в пам'яті (Guitar) і викликає саме перевизначений метод override.

4. Коли варто використовувати модифікатор new для приховування члена базового класу, і які наслідки це має?
   
Модифікатор new використовується для явного приховування (hiding) успадкованого члена базового класу, якщо у похідному класі створюється метод з таким же іменем та сигнатурою, але базовий метод не був віртуальним.
Коли використовувати: Вкрай рідко — переважно тоді, коли ви успадковуєтеся від стороннього класу і створюєте свій метод, ім'я якого випадково збіглося з новим методом з оновленої базової бібліотеки, і ви свідомо не хочете пов'язувати їх через поліморфізм.
Наслідки: Вмикається статичне (раннє) зв'язування. Виклик методу залежить від типу змінної (посилання), а не від типу об'єкта в пам'яті. Якщо звертатися до об'єкта через посилання похідного типу (Guitar), викличеться new-метод. Але якщо привести цю ж гітару до базового типу (Instrument), викличеться старий метод базового класу, що може призвести до плутанини та прихованих помилок.
