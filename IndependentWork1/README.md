# Самостійна робота No1

• Тема: Базовий синтаксис C# і оголошення класів.

## Мета

Закріпити навички оголошення класів, полів, властивостей та методів у C# для моделювання
об’єктів реального світу.

## Хід роботи
У цій роботі я створила консольний проєкт IndependentWork1 мовою C#, у якому моделювала сутності реального світу за допомогою трьох власних класів (Book, BankAccount та Student),
реалізувавши для кожного з них приватні поля, публічні властивості (включаючи read-only), конструктори з параметрами та методи з потрібною логікою обчислень чи перевірки стану,
після чого продемонструвала їхню коректну роботу в файлі Program.cs, налаштувала файл .gitignore та успішно завантажила всі зміни до існуючого GitHub-репозиторію.


## Контрольні запитання

1. Які мінімальні елементи повинен містити клас у цьому завданні?

Клас повинен містити щонайменше два приватні поля, принаймні одну публічну властивість з get та set (або read-only), 
конструктор із параметрами для початкової ініціалізації полів та мінімум один метод, що реалізує обчислювальну логіку або перевірку стану об'єкта.

2. Чому поля доцільно робити приватними, а доступ до них надавати через властивості?

Це забезпечує інкапсуляцію: приватні поля захищають дані від безпосереднього та неконтрольованого втручання ззовні, а властивості дозволяють керувати доступом, 
додавати валідацію даних при записі (set) або обмежувати можливість зміни, роблячи поле доступним лише для читання (get).

3. Для чого в класі потрібен конструктор і як він пов’язаний зі станом об’єкта?

Конструктор потрібен для створення екземпляра класу та обов'язкової початкової ініціалізації його полів. Оскільки стан об'єкта визначається сукупністю значень його полів, 
конструктор гарантує, що об'єкт з моменту створення буде перебувати у коректному та готовому до використання стані.

4. Як у Main показати, що методи класу працюють коректно?

Для цього у методі Main потрібно створити об'єкт класу, передавши необхідні значення в конструктор, викликати його методи з відповідними параметрами та 
вивести отримані результати виконання (повернені значення або змінений стан) у консоль за допомогою Console.WriteLine з зрозумілим описом.
