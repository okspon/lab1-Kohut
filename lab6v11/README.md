# Лабораторна робота No6
• Тема: Наслідування. Ключові слова base, override, virtual. Приховування членів (new).
• Інструмент: .NET SDK, IDE на вибір студента

## Мета
Навчитися створювати ієрархії класів, використовувати ключові слова base, virtual, override
для реалізації поліморфізму, а також розуміти відмінності між override та приховуванням членів
за допомогою new.

## Теоретичні відомості
• Наслідування: Механізм ООП, що дозволяє одному класу (похідному) успадковувати
функціональність іншого (базового), створюючи ієрархію “є-різновидом”.
• base: Використовується для доступу до членів базового класу, зокрема для виклику його
конструкторів або методів.
• virtual: Модифікатор, що дозволяє похідним класам перевизначати (override) метод,
властивість або індексатор базового класу.
• override: Модифікатор, що вказує на те, що член похідного класу надає нову реалізацію
віртуального члена базового класу, забезпечуючи поліморфізм.
• new (модифікатор): Використовується для явного приховування успадкованого члена
базового класу. Створює новий член у похідному класі, який має те ж ім’я, що й член
базового класу, але не перевизначає його. Виклик залежить від типу посилання.

## Контрольні запитання

1. Поясніть принцип наслідування в ООП. Наведіть приклад з реального світу.

Наслідування - це один із фундаментальних принципів об'єктно-орієнтованого програмування,
який дозволяє новому (похідному/дочірньому) класу переймати стан (поля, властивості) та поведінку (методи) вже існуючого (базового/батьківського) класу.
Це забезпечує повторне використання коду та створює ієрархічний зв'язок «є-різновидом» (is-a).
Приклад з реального світу: Базовий клас - «Транспортний засіб» (має параметри: марка, швидкість та метод Рухатися). Похідні класи — «Автомобіль» та «Мотоцикл»,
які автоматично успадковують ці параметри, але додають власні специфічні властивості (наприклад, кількість дверей у авто або наявність коляски у мотоцикла).

2. Для чого використовується ключове слово base? Наведіть приклади його застосування.

Ключове слово base використовується всередині похідного класу для звернення до членів базового класу. Основні випадки застосування:Виклик конструктора базового класу для ініціалізації успадкованих
полів:C#public Guitar(string brand, decimal price, int strings) : base(brand, price)

{
    NumStrings = strings;
}
Виклик реалізації методу базового класу у перевизначеному або прихованому методі:C#public override void PlaySound()
{
    base.PlaySound(); // Виклик базового звучання
    Console.WriteLine("Додатковий звук гітари");
}

3. У чому полягає різниця між virtual та override? Як вони забезпечують поліморфізм?


virtual використовується в базовому класі для оголошення того, що метод, властивість
чи індексатор можуть бути змінені або перевизначені у похідних класах.override використовується в похідному класі для надання нової (власної) реалізації віртуального члена базового класу.
Забезпечення поліморфізму: Завдяки таблиці віртуальних методів (VMT), коли метод з модифікатором override викликається через змінну типу базового класу (наприклад, Instrument myInst = new Guitar()),
програма під час виконання (runtime) викликає метод саме того класу, об'єкт якого реально знаходиться в пам'яті (Guitar.PlaySound()), а не базового.

4. Коли варто використовувати модифікатор new для приховування члена базового класу,і які наслідки це має?

Модифікатор new використовується для явного приховування (shadowing/hiding) невiртуального члена базового класу, коли у похідному класі створюється новий член із таким самим ім'ям та сигнатурою
Коли використовувати: Його застосовують рідко - переважно тоді, коли базовий клас перебуває в сторонній бібліотеці (і ви не можете зробити його метод virtual), але вам потрібно визначити у своєму класі метод з таким самим ім'ям,
свідомо розірвавши поліморфний зв'язок.Наслідки: На відміну від override, метод з new створює абсолютно незалежний член. Який саме метод буде викликано, залежить виключно від типу змінної-посилання під час компіляції
(статичне зв'язування): Якщо посилання типу похідного класу
(Guitar g = new Guitar()) $\rightarrow$ викликається new-версія з Guitar.Якщо посилання типу базового класу (Instrument i = new Guitar()) $\rightarrow$ викликається оригінальна версія з Instrument.
