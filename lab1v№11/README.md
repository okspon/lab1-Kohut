# Лабораторна робота No1

• Тема: Створення першого проєкту. Класи, об’єкти, конструктори та деструктори.
Середовище розробки.


## Мета
Ознайомитися з середовищем розробки, навчитися створювати класи та працювати з базовими
елементами ООП у C#. Налаштувати середовище розробки.
Теоретичні відомості

• Клас - це шаблон для створення об’єктів. Він описує, які дані (поля) та яку поведінку
(методи) матимуть його екземпляри.

• Конструктор - це спеціальний метод, що автоматично викликається під час створення
нового об’єкта (new ClassName()). Його основне завдання - ініціалізувати початковий стан
об’єкта.

• Деструктор - це метод, що викликається перед тим, як об’єкт буде знищено збирачем
сміття. У C# використовується рідко, але демонструється для розуміння життєвого циклу
об’єкта.

• Інкапсуляція - це механізм приховування внутрішніх деталей реалізації. Доступ до даних
класу контролюється через публічні властивості (get, set), тоді як самі дані зберігаються у
приватних полях.

## Хід роботи
Під час виконання лабораторної роботи було налаштовано робоче середовище у VS Code, створено проєкт консольного додатка на мові C# та налаштовано версійний контроль за допомогою Git і GitHub. Для виконання завдання за Варіантом 11 розроблено клас Plane, у якому реалізовано приватні поля airline і model, публічну властивість Capacity для керування пасажиромісткістю, конструктор для ініціалізації об'єктів, деструктор для відстеження вивантаження з пам'яті та метод Fly(), що виводить інформацію про стан польоту. У файлі Program.cs було створено кілька екземплярів класу Plane, продемонстровано їхню роботу та зміну властивостей об'єктів. Проєкт структуровано відповідно до вимог, додано файл .gitignore для ігнорування системних папок bin/ та obj/, після чого всі зміни зафіксовано за допомогою комітів і відправлено у віддалений репозиторій на GitHub разом із результатом роботи у файлі README.md.

## Контрольні запитання

1. Що таке клас та об’єкт? Яка між ними різниця?

Клас - це шаблон або опис об’єктів, у якому задаються їхні властивості та методи.
Об’єкт - це конкретний екземпляр класу.
Наприклад, клас Автомобіль описує, що автомобіль має колір і швидкість, а конкретний автомобіль - це вже об’єкт цього класу.

2. Для чого використовуються конструктори? Чи може клас існувати без них?

Конструктор використовується для створення та початкового налаштування об’єкта. Він задає початкові значення його полів.
Клас може існувати без конструктора, тоді система зазвичай створює конструктор за замовчуванням.

3. Чим відрізняється приватне поле від публічної властивості? Навіщо потрібна інкапсуляція?

Приватне поле доступне тільки всередині самого класу.
Публічна властивість може використовуватися ззовні класу для отримання або зміни значення поля.
Інкапсуляція потрібна для захисту даних об’єкта та контролю доступу до них. Вона не дозволяє змінювати внутрішні дані класу неправильно або без необхідних перевірок.
